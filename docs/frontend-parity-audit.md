The pre-rewrite DOM, classes, wording, and interactions are the presentation reference. The working-tree API, session, CSRF, authorization, SQLite, and upload behavior remain authoritative.

## Data-boundary result

- Operational: authenticated profile, authorization, edition identity, token inventory counts, API media assets, capsule entries, and Difusora posts.
- Presentation compatibility only: six-card analytics, manager/editorial identities, illustrator profile, demo collector cards, QR/location logs, links, points of sale, revenue/campaign values, and WhatsApp contacts.
- The compatibility values live only in `LEGACY_PRESENTATION_DEFAULTS` and are normalized once by `buildManagerViewModel`; they are not collector records or operational analytics.
- The later presentation/asset migration still needs to move these compatibility values and static image paths into authoritative database storage. No BLOB schema or asset-generation work is included here.
